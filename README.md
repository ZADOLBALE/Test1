# Голосовой помощник

Простой голосовой помощник на Python: умеет открывать сайты, искать в Google и
открывать файлы из папки `files/` — по голосовым или текстовым командам.

## Возможности

| Команда | Пример | Что делает |
|---|---|---|
| Открыть сайт | «открой ютуб», «открой github» | Открывает сайт из встроенного списка в браузере |
| Открыть URL | «открой example.com/page» | Открывает произвольную ссылку |
| Поиск | «найди котиков», «загугли погоду» | Ищет в Google |
| Открыть файл | «открой файл readme» | Ищет файл в папке `files/` и открывает системной программой |
| Выход | «стоп», «выход», «пока» | Завершает работу |

Поддерживаемые сайты по имени: youtube, google, vk, telegram, github, habr,
wikipedia, avito, ozon, netflix, yandex, почта (и другие — см. словарь `SITES`
в `assistant/commands.py`, легко добавить свои).

## Требования

- **Python 3.10+** (используются современные аннотации типов)
- Микрофон — только для голосового режима
- Интернет — для распознавания речи (Google Web Speech API)

## Установка

### 1. Скачайте проект и перейдите в его папку

```bash
cd path/to/project
```

### 2. Создайте виртуальное окружение

**Windows:**
```powershell
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

Зависимости:
- `SpeechRecognition` — распознавание речи с микрофона
- `PyAudio` — доступ к микрофону (нужен только для голосового режима)
- `pyttsx3` — офлайн-озвучка ответов (необязательно)

#### Если PyAudio не устанавливается

**Windows:**
```powershell
pip install pipwin
pipwin install pyaudio
```
либо скачайте wheel с https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
и установите: `pip install PyAudio‑0.2.13‑cp311‑cp311‑win_amd64.whl`

**Ubuntu / Debian:**
```bash
sudo apt install portaudio19-dev python3-pyaudio
pip install pyaudio
```

**macOS (Homebrew):**
```bash
brew install portaudio
pip install pyaudio
```

### 4. Озвучка (необязательно)

- **Windows** — достаточно `pyttsx3` (голоса SAPI есть в системе)
- **macOS** — работает из коробки через встроенную команду `say`
- **Linux** — установите espeak:
  ```bash
  sudo apt install espeak-ng   # или espeak
  ```

Если ничего не установлено, помощник просто печатает ответы в консоль.

## Запуск

### Текстовый режим (без микрофона — для старта и отладки)

```bash
python main.py --text
```

Пример:
```
🗣  > открой ютуб
🔊 Открываю https://www.youtube.com
🗣  > найди погоду минск
🔊 Открываю https://www.google.com/search?q=...
🗣  > стоп
```

### Голосовой режим

```bash
python main.py                # русский (по умолчанию ru-RU)
python main.py --lang en-US   # английский
```

Говорите команду и делайте паузу — она отправится на распознавание.
«стоп» / «выход» / «пока» — завершение работы.

### Тест только командного модуля (без озвучки и микрофона)

```bash
python -m assistant.commands
```

## Структура проекта

```
├── main.py                 # точка входа (текстовый/голосовой режимы)
├── requirements.txt        # зависимости
├── files/                  # папка, откуда помощник открывает файлы
│   └── readme.txt
└── assistant/
    ├── commands.py         # разбор фраз в команды + выполнение (сайты, поиск, файлы)
    ├── listener.py         # слушание микрофона и распознавание речи
    └── speaker.py          # озвучка ответов (pyttsx3 / say / espeak)
```

## Частые проблемы

- **«Микрофон не найден»** — проверьте, что система видит микрофон и дала
  разрешение на доступ к нему; временно используйте `--text`.
- **«Проблема с сервисом распознавания»** — нет интернета; распознавание речи
  идёт через бесплатный онлайн-сервис Google.
- **«Браузер не найден»** — на headless-системах (сервер/WSL без GUI) браузер
  отсутствует; помощник выведет ссылку, её можно открыть вручную.

## Как добавить свой сайт

Откройте `assistant/commands.py` и добавьте строку в словарь `SITES`:

```python
SITES = {
    ...
    "твич": "https://www.twitch.tv",
}
```

После этого команда «открой твич» будет работать сразу.
